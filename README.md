# qvac-test-suite

This repository maintains and publishes the `@tetherto/qvac-test-suite` framework.

## What lives here

- `framework/` — the publishable `@tetherto/qvac-test-suite` package
- `.github/workflows/publish-framework.yml` — build and publish workflow

## Local development

```bash
cd framework
npm install
npm run build
```

Package-level documentation and usage examples live in `framework/README.md`.
